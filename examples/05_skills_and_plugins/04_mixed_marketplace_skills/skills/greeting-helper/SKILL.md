# 问候助手

一种本地技能，有助于为不同场合生成创意问候语。

<a id="description"></a>

## 描述

该技能提供关于为各种场合如生日、节日、工作事件和随意的会面等创建有思想、有创意的问候的指导。 这是混合市场中本地托管技能的示例。

<a id="usage"></a>

## 用途

当您需要执行以下操作时，请使用此技能：
- 创建个性化的生日留言
- 写下节日祝福
- 工艺专业祝贺
- 发出随意、友好的问候

<a id="examples"></a>

## 示例

**生日祝福：**
“生日快乐！ 愿今年给你带来无尽的欢乐和所有让你微笑的事情。”

**节日祝福：**
“祝您这个假期温暖幸福，新年充满无限可能。”

**职业祝贺：**
“祝贺你取得的成就！ 你们的奉献和努力确实得到了回报。”
